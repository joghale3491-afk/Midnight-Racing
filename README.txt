MIDNIGHT RACING — VERSION 36
============================

INSTALL / UPDATE
1. Extract this ZIP.
2. Upload every item inside the Midnight-Racing-v36 folder to the root of your GitHub Pages repository, replacing the previous files.
3. Keep index.html, sw.js, manifest.webmanifest, all icon files, and the audio folder together.
4. Commit the changes and open the GitHub Pages site.
5. Hard-refresh with Ctrl+Shift+R. On a phone, close and reopen the installed app; if an old icon remains, clear the site data and reinstall the app shortcut.

V36 FIXES
- Defines the missing playNoiseBurst audio helper used by nitro, power-up, and crash effects.
- Replaces the harsh continuous engine oscillator with a bundled, original engine-loop sound. Its playback pitch follows vehicle speed / simulated RPM and throttle; P1 and local split-screen P2 have separate engine loops.
- Pausing a race stops both car engine loops, pauses the music, stops the police siren and suspends the Web Audio effects engine. Engine audio resumes when the race resumes. Finishing a race stops vehicle audio.
- Repositions the main race position/lap/time HUD to the actual viewport centre; in local split-screen it is centred in Player 1's half.
- Uses versioned favicon and app-icon filenames, updates the manifest and refreshes the service-worker cache to help prevent stale or missing icons.
- Adds route-definition validation for all 31 circuits: checks point count, finite coordinates, bounds, duplicate/too-close points, path length, and self-crossing route polygons. Invalid selected tracks fall back to NEON DISTRICT. The generated spline is also sampled for invalid or collapsed segments before road geometry is built. Turn modifiers support any number of turns without generating undefined positions.

AUDIO LICENSING
- audio/midnight-racing-loop.mp3 is an original electronic night-drive instrumental synthesized specifically for Midnight Racing v36. It uses no third-party music samples.
- audio/car-engine-loop.mp3 is an original synthetic engine-like loop created for this project without third-party recordings or samples.
- Both original audio assets are dedicated for reuse under CC0 1.0 (public-domain dedication). They may be copied, remixed, and redistributed without attribution.
- Nitro, crash, power-up, and police siren effects remain generated by the game's own Web Audio code. No commercial game sound assets are included.

ICON NOTE
- Browser tab icons, bookmarks, Apple touch icon and PWA install icons now use new v36 filenames and are precached by the v36 service worker.
- Search engine result icons can take additional time to refresh after GitHub Pages is updated.

MULTIPLAYER / CLOUD NOTES
- Online ranked and tournament features still require the game's existing Supabase URL/key configuration, sign-in, database setup and Realtime availability.
- This ZIP cannot configure credentials or database policies in the user's Supabase project.

CHECKS / LIMITATIONS
- The inline JavaScript is checked with Node.js syntax validation.
- All 31 track route definitions passed the route-point validation checks in this build.
- ZIP integrity, required audio/icon files, manifest JSON and service-worker asset references are checked after packaging.
- A live gameplay session, audio playback on every device, WebGL rendering, Supabase multiplayer and search-engine crawling cannot be fully verified from this build environment. Please test on GitHub Pages after publishing.
