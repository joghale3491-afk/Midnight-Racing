MIDNIGHT RACING — UPDATED BUILD

Upload the contents of this folder to the main branch of your GitHub Pages repository. Keep index.html, manifest.webmanifest, sw.js, both icons, and supabase_setup.sql together.

Start with guest play or configure Supabase sign-in. Guest progress is saved on the same device. For accounts, cloud saves, online rooms and the server leaderboard, replace the two Supabase placeholders in index.html with your project URL and public anon/publishable key, then run supabase_setup.sql in Supabase SQL Editor. Never put a service_role key in the browser.

See README.md for controls, features, setup steps and current online multiplayer limitations.
