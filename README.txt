MIDNIGHT RACING v31

Changes:
- Ranked Multiplayer is now directly below Race Hub and Story in the side navigation.
- Existing Supabase Ranked matchmaking, human-player queue, AI grid fillers, Ranked Tickets and server standings are retained.
- An original techno soundtrack is embedded inside index.html as audio data; no separate music file or external music URL is required.
- Engine, nitro and other race sound effects remain generated by the built-in WebAudio sound system.
- Music volume and mute controls apply to the embedded soundtrack. The soundtrack pauses and resumes with the race.

Online Ranked still requires your own Supabase project URL, public anon key, configured database tables and Realtime enabled. Do not put a Supabase service-role key in the game.

Deploy by replacing the old project files with these files, including sw.js, then hard-refresh the hosted page.
